# Welcome to FluoGraphiX Documentation!

Welcome to the official guide for FluoGraphiX, your essential tool for visualizing and processing fluorimeter data. Whether you are a new user or an expert, this documentation is designed to help you get the most out of the application.

---

## What is FluoGraphiX?

FluoGraphiX is a powerful and intuitive application developed to simplify the analysis of your hydrogeological tracing data. It allows you to:

*   **Visualize** your raw data with interactive charts.
*   **Correct** interferences (turbidity, background noise) for accurate results.
*   **Convert** measurements into actual concentrations.
*   **Export** your data in various compatible formats.

## Getting Started

To begin with FluoGraphiX, follow these simple steps:

1.  **Download** the application from the [Download](/telecharger) section.
2.  **Install** FluoGraphiX on your system (Windows, macOS, Linux).
3.  **Launch** the application and explore the user interface.
4.  **Import** your first data files (DAT, CSV, XML, MV).

::: warning
**⚠️ Important:**
Ensure your data files are correctly formatted to avoid import errors. Refer to the "Supported File Formats" section for more details.
:::

### Frequently Asked Questions (FAQ)

<details>
  <summary>How do I import my data?</summary>
  <p>To import your data, click the "Import" button in the "Visualization" section. You can then select one or more files from your computer.</p>
</details>

<details>
  <summary>Can I correct turbidity?</summary>
  <p>Yes, FluoGraphiX offers advanced tools for turbidity correction. Go to the "Calculations" section after importing your data.</p>
</details>

<details>
  <summary>Is the application free?</summary>
  <p>FluoGraphiX is an open-source project developed by BRGM. Its use is entirely free.</p>
</details>
