# Bienvenue dans la Documentation FluoGraphiX !

Bienvenue dans le guide officiel de FluoGraphiX, votre outil essentiel pour la visualisation et le traitement des données issues de fluorimètres. Que vous soyez un nouvel utilisateur ou un expert, cette documentation est conçue pour vous aider à tirer le meilleur parti de l'application.

---

## Qu'est-ce que FluoGraphiX ?

FluoGraphiX est une application puissante et intuitive développée pour simplifier l'analyse de vos données de traçage hydrogéologique. Elle vous permet de :

*   **Visualiser** vos données brutes avec des graphiques interactifs.
*   **Corriger** les interférences (turbidité, bruit de fond) pour des résultats précis.
*   **Convertir** les mesures en concentrations réelles.
*   **Exporter** vos données dans divers formats compatibles.

::: info
**💡 Astuce Rapide :**
Pour une prise en main rapide, nous vous recommandons de commencer par la section [Prise en main](#premiers-pas) ci-dessous.
:::

## Premiers Pas

Pour commencer avec FluoGraphiX, suivez ces étapes simples :

1.  **Téléchargez** l'application depuis la section [Téléchargement](/telecharger).
2.  **Installez** FluoGraphiX sur votre système (Windows, macOS, Linux).
3.  **Lancez** l'application et explorez l'interface utilisateur.
4.  **Importez** vos premiers fichiers de données (DAT, CSV, XML, MV).

::: warning
**⚠️ Important :**
Assurez-vous que vos fichiers de données sont correctement formatés pour éviter les erreurs d'importation. Référez-vous à la section "Formats de Fichiers Supportés" pour plus de détails.
:::

### Questions Fréquentes (FAQ)

<details>
  <summary>Comment importer mes données ?</summary>
  <p>Pour importer vos données, cliquez sur le bouton "Importer" dans la section "Visualisation". Vous pourrez alors sélectionner un ou plusieurs fichiers depuis votre ordinateur.</p>
</details>

<details>
  <summary>Puis-je corriger la turbidité ?</summary>
  <p>Oui, FluoGraphiX offre des outils avancés pour la correction de la turbidité. Rendez-vous dans la section "Calculs" après avoir importé vos données.</p>
</details>

<details>
  <summary>L'application est-elle gratuite ?</summary>
  <p>FluoGraphiX est un projet open-source développé par le BRGM. Son utilisation est entièrement gratuite.</p>
</details>
