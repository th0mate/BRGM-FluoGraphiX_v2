# Bienvenue dans la Documentation FluoGraphiX !

Bienvenue dans le guide officiel de FluoGraphiX, votre outil essentiel pour la visualisation et le traitement des
données issues de fluorimètres. Que vous soyez un nouvel utilisateur ou un expert, cette documentation est conçue pour
vous aider à tirer le meilleur parti de l'application.

---

## Qu'est-ce que FluoGraphiX ?

FluoGraphiX est une application puissante et intuitive développée pour simplifier l'analyse de vos données de traçage
hydrogéologique. Elle vous permet de :

* **Visualiser** vos données de mesure avec des graphiques interactifs.
* **Corriger** vos courbes (turbidité, bruit de fond, interférences) pour des résultats précis.
* **Convertir** les mesures en concentrations réelles.
* **Exporter** vos données dans divers formats compatibles (TRAC, CSV).

::: info
**💡 Astuce :**
Pour une prise en main rapide, nous vous recommandons de commencer par la section [Prise en main](#premiers-pas)
ci-dessous.
:::

---

## Installation

Pour commencer avec FluoGraphiX, suivez ces étapes simples :

1. **Téléchargez** l'application depuis la page de téléchargement.
2. **Sélectionnez** la version adaptée à votre système d'exploitation (Windows, macOS, Linux).
3. **Installez** FluoGraphiX sur votre système (Windows, macOS, Linux).
4. **Lancez** l'application et explorez l'interface utilisateur.
5. **Importez** vos premiers fichiers de données (DAT, CSV, XML, MV).

::: warning
**⚠️ Important :**
Assurez-vous que vos fichiers de données sont correctement formatés pour éviter les erreurs d'importation. Référez-vous
à la section "Formats de Fichiers Supportés" pour plus de détails.
:::

### Questions Fréquentes (FAQ)

<details>
  <summary>Comment importer mes données ?</summary>
  <p>Pour importer vos données, cliquez sur le bouton "Commencer" dans la section "Visualisation" ou "Calibration". Vous pourrez alors sélectionner un ou plusieurs fichiers depuis votre appareil.</p>
</details>

<details>
  <summary>Puis-je exporter mes données vers TRAC ?</summary>
  <p>Oui, FluoGraphiX offre des outils avancés pour la conversion et l'export de vos données de mesure. Rendez-vous dans l'utilitaire de calculs et d'export après avoir importé vos fichiers.</p>
</details>

<details>
  <summary>L'application est-elle gratuite ?</summary>
  <p>FluoGraphiX est un projet open-source développé par le BRGM. Son utilisation est entièrement gratuite.</p>
</details>

<details>
  <summary>L'application est-elle compatible avec les smartphones ?</summary>
  <p>Pour le moment, il n'est pas possible de télécharger FluoGraphiX sur un téléphone. Vous pouvez cependant consulter le site web avec un tel appareil.</p>
</details>
